## Scope

- Sandbox compile pipeline with structured diagnostics (`RGS0000`–`RGS0004`) and the typed analysis contract.
- Container worker with no network, read-only input, non-root user, memory/pid/output limits, and a hard deadline.
- Flow agent step over `IChatClient`, `Then`, `Retry`, `Checkpoint`, SQLite journal with `PRAGMA user_version` 1, live run events, and an `ActivitySource`.
- `TableSlice` data API over `ITable`, with 13 tests and ADR-0010.
- Demo host: ASP.NET Core page, SSE timeline, fake model, repair loop, chart rendering, and injected policy refusal.

## Evidence

- Build: `dotnet build Runesgalder.sln -c Release` — 0 warnings, 0 errors.
- Tests: `dotnet test` — 68 of 68 passed (29 Flow, 34 Sandbox, 5 Demo).
- Demo: analysis run via SSE and browser returned "Revenue peaks in 2025-12 at 55140." with the same 12-point chart; browser run finished in 588.3 ms with 44.7 ms of sandbox time. Refusal run failed at compile with `RGS0001` on `System.Net` and never reached the worker.
- CI: `Analyze C#`, `Build and test (ubuntu-latest)`, and `Build and test (windows-latest)` passed on `c1c3cd5` and on the G2 evidence commit `2a9c116`.
- Security review: policy refusal path demonstrated end to end; container arguments and limits are covered by tests. The full escape-test suite is a Phase 2 deliverable and is not claimed here.
- Secret scan: GitHub secret scanning and push protection are enabled on the repository (checked 2026-11-23). The reviewed diff contains documentation and source only; no credentials or machine-specific paths were added.

## Risks

- Roslyn compilation still runs on the host; only generated-code execution is container-isolated. Recorded as a known v0.1 limit.
- `SandboxContainerRunner` is verified by hand on this machine and by argument tests in CI, not by a Linux E2E job yet.
- Cold container start can push a run close to the 10 s wall clock; the worker warm path is ~0.6 s end to end.
